# 小红书离线包

构建依据：用户指定的 `vibe coding/小红书小工具/xiaohongshu skill/SKILL.md`（v1.2.0），以及其 `zip-artifact-spec.md`、`device-capabilities.md`、`cross-platform-h5.md`。本次复核日期：2026-11-05。

`tools/build-xhs.cjs` 从网页入口追踪本地脚本和样式，输出独立的离线包到 `output/xiaohongshu/玫瑰战争-小红书离线版.zip`。网站与离线版同步使用历史导读、地图、人物故事与手机导航；13 张原图保留在项目中。

## 包内适配

- 根目录直接提供唯一的 `index.html`；仅包含允许的静态文件类型，没有构建配置、测试、源码映射或系统文件。
- 所有脚本外置、资源相对引用；无联网请求、外链字体、内联脚本、动态代码执行、自建 CSP 或禁用能力。
- 删除全屏按钮和 Fullscreen API 调用，以既有 CSS 书框适配容器。保留本地合成音效；音频上下文不可用时可静默继续阅读。
- 13 张原图生成 WebP 副本，最长边不超过 1200px、不裁切；单图最大约 184 KB。含新增详读与地图的 ZIP 约 1.96 MB，满足 skill 推荐的压缩包小于 2 MB、单图小于 500 KB。
- 增加安全区 fallback、封面语言按钮安全区和容器触摸样式。正文页内纵向滚动，手机单页底部按钮固定，翻页顺序为故事上页 → 续页 → 本章互动；历史按缘起、经过、余波、地图四页阅读，导读和图谱为两页。常驻上一章及返回来处，支持正文横滑与章节边界切换。
- 保留相同 localStorage 键。小工具容器存储与外部网站各自隔离，网页已有进度不会自动导入。

## 验证

`tests/xhs-container.test.cjs` 解压实际交付 ZIP，在嵌套路径的本地服务器上施加严格 CSP：只允许包内脚本；禁用 connect、worker、frame、object、表单跳转等，并拒绝外网资源。CSP 只由测试服务器提供，不写进包。

完成的检查：

- 入口位置、文件白名单、ZIP CRC、脚本语法、全部引用资源、13 张 WebP 加载。
- 320×568、390×680、430×792 的顶部/底部安全区；中英文封面、目录两页、图谱人物与返回；844×390 横屏和 1366×768 桌面。
- 复用移动端测试，验证故事与互动翻页、真实触摸横滑、反向滑动、竖向滚动、取消触摸、游戏手势排除、连续点击锁定、长文末行、大字号、三页前传、全景、家谱、横竖切换、小游戏完成与下一章。
- 书签、游戏 DOM、未确认决定、滚动位置保持；刷新恢复、重新开始；已完成互动主动重走、取消确认、重新选择与原章节解锁保持。
- 新增历史专项复核21页正文的实际末行、9个地图地点、历史页码书签、人物使命入口及不解锁人物活动。

报告和截图位于 `output/xiaohongshu/qa/`；构建清单位于 `output/xiaohongshu/build-report.json`。

验证是在浏览器模拟容器 CSP 和触摸环境中完成，未登录小红书平台上传，也未执行小红书官方模拟器或真机验收。

## 重建

本机已存在的依赖通过环境变量引用，不放入 ZIP：

```sh
SHARP_PATH=/路径/到/sharp node tools/build-xhs.cjs
PLAYWRIGHT_PATH=/路径/到/playwright node tests/xhs-container.test.cjs
```

测试通过后复制输出 ZIP 到桌面。上传该 ZIP 本身，无需再套一层目录或重新压缩整个项目。
