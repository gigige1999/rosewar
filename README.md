# 玫瑰战争 · 血与花之书

直接在浏览器打开 `index.html`。无需安装，无外部字体、脚本或网络依赖。

在线阅读：[https://gigige1999.github.io/rosewar/](https://gigige1999.github.io/rosewar/)

GitHub Pages 从 `main` 分支根目录发布，提交到该分支后自动更新；`.nojekyll` 让本地静态资源直接提供服务。验收截图、临时产物和本机配置由 `.gitignore` 排除，不随源码提交。

## 阅读方式

1. 轻触暗红封皮，观看红白玫瑰开谢的序幕；可跳过。右上角「中文 / EN」切换封面版本并保存偏好，内页为中文。
2. 展开后总是先到卷首目录，可以先点「展开家族图谱」认清人物，再选择「人物命运」或无需角色的「历史全景」。已有进度时，目录下方提供「接着书签读」，进入目录与图谱本身不会改变原书签。
3. 人物路线：先翻阅三页人物前传，认识他的家人、处境与经历。六人各有七章，每章左页分为两页故事：先讲清当年的事件，再说明人物关系、前因后果及右页抉择所处的年代。右页保留三个小游戏与四次人生抉择；先选择行动、读到内心声音，再「以此落笔」。任何选项都能推进，之后读到这一决定的后果和真实历史对照。
4. 全景路线：沿 1455—1487 年的七个时间节点自由翻阅，无角色、无解谜门槛；每章保留配图位置并说明前后因果。
5. 书页右上角的「字」可进一步放大正文；默认正文已增至桌面 17px、手机 18px，放大后为 20px / 21px。

### 读前家族图谱

打开家谱先进入「先看懂关系」，分四张小图逐步认识人物：谁在守住或争夺王位、两位玛格丽特各是谁的妻子与母亲、约克家的父亲与叔父、沃里克两个女儿的婚姻。每张只放六位不同的人物，图旁直接写出「夫妻」「儿子」「女儿」，并用一句结论和几段通俗文字解释这层关系如何影响故事。省略的人物会在图旁说明；安妮两段婚姻标出先后年份，同名人物分别介绍。

点姓名可查看此人的生平，以及按父亲、母亲、配偶、子女、兄弟姐妹整理的亲属关系；点亲属姓名可接着追溯，六位主角可直接打开各自前传。前传只供预览，仍由读者主动选择是否开始这条人物路线。

需要追溯更远的血缘时，切换「查完整家谱 · 42 人」。详细模式保留「王位的来处」「兰开斯特与都铎」「约克王室」「内维尔的婚姻」四张分谱，可逐支展开后代或一次展开全部，也能随时返回入门图。枝线只连接相邻两代，婚姻单独标明；六位主角有星记，不把政治结盟画成血缘。

桌面左页看图、右页读说明；手机将两页分开，点姓名翻到人物释读，用「回到关系图／家族树」回到所选人物。页顶「家谱」可随时查阅；查阅、跨谱与返回不会完成游戏、改变角色或覆盖故事书签。

### 六条混合互动路线

| 人物 | 三个游戏章节（其余四章为人物决策） |
| --- | --- |
| 安茹的玛格丽特 | 王冠护送 → 有限载重的补给行囊 → 残页拼合 |
| 沃里克伯爵 | 封印天平 → 判断横风与力度的射箭 → 旧物翻牌配对 |
| 爱德华四世 | 联动太阳轮 → 继承残页拼合 → 旋转道路接续 |
| 玛格丽特·博福特 | 烛光密信 → 封印顺序记忆 → 婚约天平 |
| 理查三世 | 白野猪骑士棋 → 旋转道路 → 风中试射 |
| 约克的伊丽莎白 | 童年旧物翻牌 → 红白玫瑰刺绣 → 封印记忆 |

共 18 个小游戏章节、24 次人物抉择、72 条行动与后果，覆盖 12 种游戏机制；**同一人物路线内的游戏机制不重复**。决策没有正确答案、分数或失败；三个选项分别体现不同的牵挂与代价，其中一个对应可确认的历史行动。人物内心为文学创作，其他道路明确标记「架空推演」。人物死亡后的决策以注明年代的生前回望呈现，不让逝者参与后来的事件。

每次确认的决定会进入「手稿」，记录行动、具体后果、余响与历史旁注；下一章保留上一笔的余响，尾声可重读自己的全部决定。各次决策是从真实处境出发的独立分岔，历史底本仍按真实年份继续，不把几次相互独立的假设拼成已发生的历史。

游戏不计时，保留点击、拖放、触摸和键盘操作。翻牌失配后可直接点下一张；记忆失误保留已记住的片段，并可展开小抄；射箭显示落点预览，射入内环即可；行囊可用多种组合出发，并按所带物资写出不同旅途描述。接路实时点亮已连通的部分，拼片可展开完整纹样。卡住时可看「一点提示」或「重新摆放」。

「目录」返回卷首双路线；「年表」可回读已解锁的角色章节，全景模式则可跳至任意年份。「人物」保留各自独立的互动记录；历史章节解锁共享，换人从第一章开始，但不会自动完成其机关。桌面左页底部的「故事前页 / 故事续页」只翻本章正文，保留右侧游戏、尚未确认的选择与阅读位置；书本下方按钮切换整章。焦点在故事页内时，左右方向键翻正文；游戏区域内的方向键优先用于游戏。

声音默认关闭，可在书页工具中开启轻柔音调与翻页声。桌面对页宽度最多 1100px，按浏览器高度收纳。正文首张故事页保留完整章图，续页收起画位，让叙事有更多空间；人物介绍页采用肖像与身份并排。页眉、故事分页与页码固定，内容较长时页底显示「继续阅读」，点击可向下阅读，再点「回到页首」返回。

手机竖屏采用单页羊皮书：书框与底部翻页控件保持在屏幕内，长内容在当前书页里上下滚动。每章依次为「故事上页 → 故事续页 → 本章互动」，可用页签、前后按钮或在正文中左右轻扫切换；完成互动后才可进入下一章。切换保留游戏、未确认的决定与各页滚动位置，刷新后可由书签恢复到故事页或互动页。手势会避开游戏、按钮与表单，竖向阅读不会误触翻页；动画采用轻柔滑动与纸页阴影，系统减少动画设置会自动生效。

移动端目录的人物与全景、人物选择与三页前传、家族树与人物释读、全景画页与年表、战争尾声与人物终章也使用同一套页签。点家谱姓名可直接翻到释读，再回到原树枝。页顶保留「目录」「家谱」「字」，其他功能收在「更多」里。窗口宽度超过 760px 时恢复桌面对页，原阅读进度继续保留。

进度随操作保存到当前浏览器的本地存储，包括游戏、尚未确认的意向、已落笔的决定、手稿、每个人物每章的故事页码与故事/互动侧、全景年份与画页/年表侧、字号与封面语言。刷新后翻开封皮，先到目录，再由「接着书签读」恢复上次位置；「史料与书前记」可重新开始。v1 / v2 / v3 存档自动迁至 v4：保留验证过的阅读解锁及可兼容的游戏进度，旧知识题不会被冒认为你对新困境作出的决定。原 v4 存档无需重置；没有新增页码或侧别时，从第一张故事页/画页开始。

## 目录

- `index.html` / `styles.css` / `reading.css` / `folio.css` / `app.js`：书本呈现、紧凑对页、左文右互动、阅读字号与声音。
- `content.js`：六位人物、七章史实、42 段角色声音与旧存档迁移所需的原题数据。
- `stories-lancaster.js` / `stories-york.js` / `stories-court.js`：六人三页前传与每章两页的通俗叙事；区分主年表、人物折页与后来余页。
- `stories.css`：故事与前传正文、独立分页、续页与目录书签样式。
- `mobile-reader.js` / `mobile-reader.css`：移动单页书框、统一页签、触摸翻页与动画、原页面 DOM 和滚动位置保留。
- `genealogy-guide.js` / `genealogy-data.js` / `genealogy.js` / `genealogy.css`：四张入门关系图、42 位人物的完整分谱、具体亲属称谓、跨谱关联及主角前传入口。
- `engine.js`：v4 决策与互动状态、章节解锁、双路线书签、按人物和章节保存的 `storyPages`，及 v1 / v2 / v3 存档迁移校验。
- `activity-data.js`：六条路线的 42 章互动安排、人物决策、心理动机、后果、余响与史实旁注。
- `minigames.js` / `minigames.css`：六种基础游戏及旧存档验证。
- `mixed-activities.js` / `mixed-activities.css`：混合互动接口、新增六种机制、决策预览/确认/后果与游戏素材。
- `cover-polish.css` / `decisions.css`：精简封面、放大肖像、个人手稿与决策余响样式。
- `chronicle.js` / `chronicle.css`：可自由跳读的图文历史时间轴。
- `assets/art-frames.js`：空图版与未来图片入口；旧 `assets/chronicle-scenes.js` 为归档文件，不再加载。
- `assets/ornaments.js`：统一纹章与玫瑰动画素材。
- `SOURCES.md`：历史资料入口、疑点及文学创作边界。
- `output/preview-v3/`：第三版桌面与手机验收截图；`output/design-v3/` 为紧凑书页预览。v2 目录保留旧版记录。
- `tests/`：状态逻辑与浏览器流程验证。
